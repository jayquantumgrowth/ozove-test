# Ozove — Marketing Site

The AI-native production layer for digital marketing agencies.

## Structure

- `index.html` — homepage (static, no build step)
- `css/style.css` — full design system implementation
- `js/main.js` — scroll reveals, mobile nav, live pipeline ticker
- `assets/fonts.css` + `assets/fonts/` — self-hosted fonts (Inter Tight, Inter, Instrument Serif, JetBrains Mono)
- `DESIGN.md` — brand system & design blueprint (guiding principles for all pages)

## Run locally

No build step. Open `index.html` directly, or serve it:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## Before launch

All metrics, ratings, testimonials, and client logos are **placeholders** — replace
with real figures and quotes (see the notes at the end of the homepage copy doc).
